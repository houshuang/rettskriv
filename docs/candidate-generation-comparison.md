# Candidate safeguards on more historical passages

The experimental ranker now uses lemma/paradigm alternatives, narrow preservation
rules and per-target schema constraints. It remains outside the production engine.
The new experiment found useful coverage gains **and another unsafe selection**:
valid dictionary forms and schema-valid answers still do not establish meaning or
agreement in context.

## Changes prompted by the earlier failures

`tools.sample_ranker` defaults to `--policy guarded`; `--policy legacy` retains the
original proposal algorithm. `tools/ranker_candidates.py` implements the guarded
policy for uncertain tokens:

- Offer all matching Ordbank past-tense paradigms for historical `-ede` forms,
  rather than one frequent surface form. Exclude adjective-only candidates such as
  `skrevede` from the finite-verb alternatives. Preservation is always available.
- For habitual `plejede/pleiede at/å`, offer `pleide`, excluding care/tend `pleiet`.
  Outside this pattern the readings remain ambiguous. See [Bokmålsordboka](https://ordbokene.no/bm/pleie).
- For `i Vejret`, offer `været`, excluding unrelated `veirett`. Both
  [historical Danish](https://ordnet.dk/ods/ordbog/vejr) and
  [modern Norwegian](https://ordbokene.no/nob/bm/69203) document the expression.
- Lock the observed foreign phrase `mixed drops` and uncertain forms immediately
  followed by a numbered footnote marker, such as `Væræ1)`, to preservation.
  These are narrow safeguards, not language detection or comprehensive dialect handling.
- Do not respell an already recognised infinitive to another lemma: `klage` must
  not acquire `klake`'s past forms through another spelling rule.
- Preserve uncertain `-ede` forms between an adjacent possessive and a recognised
  noun. The fresh passage `Hendes opkastede Læbe` exposed the need for this guard:
  a finite-tense proposal does not establish an attributive form's agreement.
  This deliberately withholds some valid modernisations; it is not a full parser.

The last two safeguards were completed after freezing the paid comparison, as
explained below. No production lexicon or engine decision changed in this round.
Existing explicit protected spans still take precedence in the ranking adapter.

`prepare-keyed` emits a provider-independent packet and JSON schema with one enum
per target. The model returns exact strings or `__KEEP__`; `apply-keyed` enforces
exact key coverage and candidate membership locally. Wrong spelling, casing,
missing keys and extra keys fail closed. Original offsets are reconstructed from
the frozen packet, not generated by the model. Keep the same cases and seed when
preparing and decoding. The original array interface remains available.

## Fresh source sample and frozen comparison

Thirty passages: six each from Lie's *Den Fremsynte* (1870), Elster's *Tora Trondal*
(1879), Kielland's *Garman og Worse* (1880), Skram's *Sjur Gabriel* (1887), and
Garborg's *Bondestudentar* (1908). Lie is a newly added author/book in this series.
The first four come from [MeMo v1.1](https://huggingface.co/datasets/MiMe-MeMo/Corpus-v1.1);
Garborg comes from [Runeberg's edition](https://runeberg.org/gaskriftir/1-1908/).
Raw OCR is retained, including errors and page furniture.

The packet contains 7,454 whitespace-delimited strings, or **6,583 Rettskriv word
tokens**. Sampling rejected any case-insensitive 12-word shingle shared with the
previous source packets, existing 27-book corpus, or an already selected passage.
Garborg page 25 was excluded; pages 55, 80, 105, 130, 155 and 180 were used.
MeMo blocks of at least 40 whitespace words were shuffled with `fresh-v2:<book>`.
Source URLs, block/page identifiers and SHA-256 hashes are retained privately.
This is not author-disjoint or human-adjudicated gold; absence of exact shingle
matches is not proof of independence. These passages are now development evidence.

Freeze 173 targets, then compare legacy and guarded choices at those **same
positions**. Twelve candidate sets differ; one target (`lurede`) has no legacy
alternative and is source-only in the matched legacy arm. The guarded arm also
supplies candidate notes, so this compares the proposal policies plus their notes,
not candidate strings in isolation. It does not estimate overall candidate recall.

Ten Gemini 2.5 Pro calls: one per book per policy, temperature 0, seed used for
packet/candidate ordering `paired-fresh-v2`, requested thinking budget 4,096,
output cap 10,000. API modelVersion was `gemini-2.5-pro`. Both arms used the new
keyed schema. The provider's schema subset omitted `additionalProperties`; local
validation enforced exact keys. See [structured output documentation](https://ai.google.dev/gemini-api/docs/structured-output).
There was one run per policy, so model variability is not measured.

| Result at the same 173 positions | Legacy | Guarded prototype |
|---|---:|---:|
| Complete, locally valid book responses | 5/5 | 5/5 |
| Additions to baseline edits | 48 | 50 |
| Baseline edits vetoed | 1 | 2 |
| Baseline edits replaced with a different edit | 0 | 0 |

Counts are behavior, **not accuracy**. All responses passed validation, unlike the
previous experiment's out-of-choice failures. Schema validity does not certify
linguistic safety. Relevant differences and failures:

| Real occurrence | Legacy selection | Guarded selection | Interpretation |
|---|---|---|---|
| `lurede vi os … til at mødes` (Lie, block 51) | preserve | `lurte` | Newly available past form |
| `sprøjtede højt i Vejret` (Skram, block 123) | preserve | `været` | Dictionary-supported expression |
| `drejede den sig` (Lie, block 117) | `dreiet` | `dreide` | Valid past variants, not an accuracy gain |
| `den lækkede` (Skram, block 113) | `lekket` | `lakk` | Valid past variants, not an accuracy gain |
| `Kandidat Delphin` (Kielland, block 217) | `kandidat` | preserve | Additional capitalization veto; no semantic gain claimed |
| `Hendes opkastede Læbe` (Lie, block 117) | `oppkastet` | `oppkastet` | Unsafe attributive agreement; warning was ignored |

Both arms preserved `Becker` against the baseline's `bekker` and abstained on the
OCR form `than` and dialect `loti`. The latter are useful abstentions, not evidence
that all OCR or dialect forms are recognised. Other selected additions remain
unadjudicated; no precision score is inferred from Codex's inspection.

## Final safeguards versus the paid prototype

Inspection of the frozen candidates exposed unrelated `klaka/klaket` alternatives
for `klagede`. The paid guarded run selected `klaget`, so those particular invalid
alternatives did not become edits. The final generator removes them.

Inspection of the completed responses exposed `opkastede -> oppkastet` despite a
note instructing preservation in adjectival contexts. The final possessive/noun
guard locks that target. Replaying the final generator at the same 173 positions
changes exactly these two candidate sets; the deterministic baseline is identical.
The saved guarded answer now fails validation on `oppkastet`. It is **not silently
repaired or reported as a successful final-policy model run**. No extra paid call
was made after these fixes, and there is no post-fix accuracy claim.

An offline replay of the earlier real failure passages confirms: habitual
`plejede` offers `pleide`; `Vejret` offers `været`; `mixed drops` and footnoted
`Væræ` preserve; finite `skrævede` excludes adjective-only `skrevede`. Ambiguous
dialect `trøit` is still unresolved. The narrow phrase/footnote rules cannot replace
source-aware span annotations. Grammar and historical sense analysis remain the
main limits; adding another modern dictionary alone would not resolve them.

## Reproduction and validation

```sh
python3 -m tools.sample_ranker input.json frozen --policy guarded --seed study-seed
python3 -m tools.context_ranker prepare-keyed frozen/cases.json request.json --seed study-seed
# Submit request.packet using request.schema; save the raw keyed answer object.
python3 -m tools.context_ranker apply-keyed frozen/cases.json predictions.json \
  --seed study-seed --baseline frozen/baseline.json --answers answers.json
```

For matched experiments, freeze target positions first, then substitute each
policy's choices at those positions; independently sampling each arm confounds the
comparison. The private study retains both the original frozen prototype and final
candidate replay in `out/candidates-v2/`, including raw requests/responses, usage,
source files, overlap exclusions and rejected saved answers. No source corpus or
credentials are committed.

61 unit/regression tests pass. The keyed CLI round-trip matches the saved valid
book predictions; final candidate replay demonstrates strict rejection of the new
attributive failure. Compilation and whitespace checks pass. Ten calls cost an
estimated **$0.5170**, bringing this thread's model studies to **$0.9212**, based on
reported input/output/thinking tokens, not billing statements. No paid retries or
outstanding requests remain. Independent linguistic adjudication is still needed
before these experimental proposals can justify production adoption.
